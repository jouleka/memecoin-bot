# Security policy

## Supported versions

Only the latest commit on `main` is considered for security fixes. This project is experimental
and has not received an independent security audit.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, private infrastructure details, wallet
data, or exploit steps in a public issue.

Use the repository's **Security > Report a vulnerability** form. If private vulnerability
reporting is unavailable, contact the maintainer through a private channel listed on their GitHub
profile. Include the affected commit, impact, required preconditions, and minimal reproduction
steps.

## Project boundary

The repository is paper-only. It must never contain private keys, seed phrases, API tokens,
production credentials, identifying production-host details, or a live-order path.
